QT3 Microscope runs the whole confocal setup in one window: laser, flip mirrors, power, piezo stage, camera, photon-counter scope, image scans and XYZ optimization. This guide is for everyday use on the VQLM; the TQLM is being ported. Installing, updating, setup profiles, the files the program keeps and how the code works are in the QT3 Microscope developer and expert guide.

Starting the program

Double-click QT3 Microscope on the desktop (it is also in the Start menu and taskbar). No terminal window opens; anything that used to appear there goes to the Log section at the bottom of the window. The taskbar button shows the QT3 logo and can be pinned.

At launch the program:

  1. Loads the VQLM setup profile (config_files/VQLM.yaml), which decides which instruments and tabs appear.
  2. Connects the flip mirrors and puts each one back where it was when the program last closed.
  3. Connects to the QICK-DAWG board for the laser. It does not turn the laser on or off.
  4. Restores the window size and, if you closed it less than 2 hours ago, which sections were folded, which were popped out and which tab was open.

At launch the piezos move: back to where they were when the program last closed, if that was less than 2 hours ago, otherwise to 0, 0, 0. The Stage section's Go to last button, with the last position and when it was saved beside it, moves them back to that last position at any time.

To make the shortcut on a new PC, or to start from a terminal to see an error, see Installing and updating in the developer guide.

The window at a glance

Measurements sit in the middle, the scope and log along the bottom, and the instruments in a drawer on the right.

Drag the divider between the middle and the drawer to change the drawer's width. View > Show instrument drawer hides it completely; View > Drawer sections chooses which sections it lists. Help > User Manual opens this manual.

Instrument drawer

Click a section's header to fold or open it; a folded header still shows a one-line summary. Open all and Fold all at the top of the drawer do every section at once.

Pop-out. The ↗ button at the right of a header moves that section into its own window, which you can move to another part of the screen. The panel keeps running; nothing reconnects. The drawer keeps a line with Show (bring the window to the front) and Bring back. Closing the window, its ↙ Back to drawer button, or View > Bring all windows back to the drawer returns it.

Laser (QICK-DAWG). Laser ON and Laser OFF switch the excitation laser. The large label shows ON (green) or OFF (gray); the header has small ON/OFF buttons that work while folded. The connection is checked every 30 s; use Reconnect if it drops. When the program cannot tell whether the laser is on, the label reads Laser: unknown, ON last or Laser: unknown, OFF last, with diagonal yellow stripes mixed with green (last ON) or gray (last OFF), and the Laser chip's dot is split the same way. "Last" is the last state this program set or read, even from an earlier session; plain yellow "unknown" means it has never known.

Flip mirrors. Mirrors M5–M8 on the DAQ's PFI2–PFI5 lines, each shown UP (green) or DOWN (gray) with a Toggle button. All up and All down move every mirror. The preset buttons (for example "532nm - SPCM - Confocal") set the mirrors for a light path; the button of the preset that matches the mirrors right now is highlighted. Initialize (sync UP) drives every line UP to resynchronize if a mirror was moved by hand. Connect / Disconnect are only needed after a DAQ problem; the panel connects by itself at launch.

Automatic flip mirrors (off by default; turn on in File > Preferences with Switch the mirrors automatically). When on, opening the Camera tab moves the mirrors to the camera. Opening Image scan or XYZ Optimization, or starting any scan or the scope, moves them to the photon counter, and a scan waits for the mirrors to settle before it starts. Only the detection mirrors move (listed under flippers: auto: in the profile), so the 532 nm / SuperK or Santec / white light choice stays as it is. The mirrors don't move at launch, and they stay on the counter if you open the Camera tab while a scan is running.

Power at objective. Start reads the PDA100A2 photodiode continuously and shows the power at the objective in mW, with the photodiode voltage beside it. Stop ends the readings and frees the DAQ. Double-click a reading to enlarge it for reading across the room; double-click again to shrink it.

Stage (piezos). Type a position in µm in an axis's box and press Set; Current shows where the piezo is. To step with the keyboard, tick Arrow-key stepping: ←/→ move X, ↑/↓ move Y and +/− move Z by each axis's Step (default 0.1 µm). Keys only act while the Stage section is open and you are not typing in a box. Stage moves are refused while a scan is running.

Scope (SPCM count rate)

The scope plots the SPCM count rate over time, with the latest value in large blue text.

  • Start begins reading; Pause stops it and keeps the trace; Reset clears the trace. The header's Start/Pause buttons work while the scope is folded.
  • Time per sample (s) sets how long each point counts (default 0.01 s).
  • Raw counts shows counts per sample instead of counts per second.
  • Save writes the trace. Choose PNG to get the picture plus an HDF5 file of the data with the same name, or HDF5 for the data only. The default name is scope_YYYYMMDD_HHMMSS.

The scans share the photon counter with the scope: a scan pauses the scope while it runs and restarts it afterwards if it was running.

Size and pop-out. Drag the bar just above the scope up or down to make the plot taller or shorter; the height is remembered. The ↗ button in the scope's header moves it into its own window, which is handy beside the XYZ Optimization tab or on another screen; ↙ Back to main window (or closing that window) puts it back. The Scope - SPCM chip in the top strip shows the latest rate.

"Is the SPCM on?" warning. If the first reading of the scope, a scan row or an optimization scan is exactly 0 counts, a warning window opens and the Log says so. Check that the SPCM is switched on and plugged in. The window closes by itself as soon as counts come in, or you can close it.

Camera tab

The Camera tab shows live video from the microscope camera (a Thorlabs CS165MU on the VQLM). The camera is opened the first time you press Play, not at launch.

  • ▶ Play starts live view and ⏸ Pause freezes the last frame, which can still be zoomed, measured against the crosshair or saved. Leaving the tab pauses live view; press Play again when you come back.
  • Exposure (ms) and Gain (dB): type a value, drag the slider, or turn the mouse wheel over either (hold Shift for finer steps). Auto exposure keeps the brightest pixels near 60% of full scale.
  • Contrast: Auto stretches each frame. Untick it to show the Black and White levels, which start at the last auto values, and type your own. Saturated pixels in red marks pixels at full scale.
  • View: the mouse wheel zooms, dragging pans, and Fit, 1:1 and 2× set the zoom. Crosshair and Reticle (a circle with an adjustable diameter (px)) can be shown together; Shift+click or right-click on the image moves them, and Center puts them back in the middle.
  • Snapshot saves three files: a PNG as shown on screen, the raw camera counts as a 16-bit _raw.tif, and a .json with exposure, gain and piezo position. They go to M:\qt3microscope_camera unless you pick another folder with Folder….
  • Release lets ThorCam open the camera while QT3 Microscope stays open. Press Play to take it back.

With automatic flip mirrors turned on in Preferences, opening this tab moves the mirrors to the camera.

Image scan tab

An image scan is a 2D confocal map in X and Y at the current Z, centered on the reference position. The reference position is the X/Y the piezos were last set to outside a scan (by Set, Go to position, an optimization or launch). During a scan the piezos sweep away from it, but it stays fixed, and they return to it when the scan ends. The text under the settings shows it, and Optimize Position jumps to the XYZ Optimization tab.

Settings. Range (µm) is the width of the square (default 80), Number of pixels is per side (default 80), and Time per row (s) is how long each line takes (default 1).

Running a scan.

  1. Press Start scan. The newest scan fills the left image; a green line marks the row being scanned and a blue circle marks the reference position.
  2. Pause stops after the current row, and the button turns into Continue. While paused, the stage and scope are free to use.
  3. Cancel ends the scan early, running or paused. The partial image is kept, marked "(canceled)".
  4. To give up on a paused scan and start a fresh one, double-click Start scan. This is the same as Cancel then Start. A single click while paused only shows a reminder.

When a scan completes or is canceled, the piezos go back to the reference position. Image scans are numbered 001, 002, …

Pinned scan (right image). The right image holds a scan to compare against. Pin → pins the scan shown on the left; the Pinned list picks any earlier scan; Unpin clears it. If you have not pinned anything by hand, the previous scan moves to the pinned side automatically when a new scan starts. A scan you pinned by hand stays until you change it.

Orange box. On the pinned image, an orange rectangle outlines the area of the scan on the left. It is solid when the two scans were taken at the same Z and fades as their Z values differ, fully faint at 5 µm apart. Each image's title gives its Z.

Gallery. The column on the right lists every scan as a thumbnail, newest on top; scroll it with the mouse wheel. Click a thumbnail to show it on the left, press its Pin to pin it, or × to remove it from the list (not possible for a running or paused scan). A blue border marks the scan on the left and an orange border the pinned one.

Brightness. Under Image settings, type Minimum and Maximum in counts/s and press Normalize; Auto goes back to scaling each image to its own data. The thumbnails follow the same scale.

Moving to a spot. Right-click a point on either image and choose Go to position to move the piezos there.

Saving. Save scan saves the left scan and Save pinned the right one. Choose PNG to get the picture plus an HDF5 file with the same name, or HDF5 for the data only. The HDF5 layout matches qdlscan's, so existing analysis scripts read it.

The disk button under the plots offers two choices: Save scan … on its own as PNG (the picture only) or Save both plots side by side as PNG. Saved pictures are always black on white.

XYZ Optimization tab

Each Optimize button scans one axis through the current position, fits a Gaussian and moves the piezo to the fitted peak. If the fit fails, the piezo goes back to where it started, and the status line says so.

Settings. Range XY (µm) is the scan width for X and Y (default 3), Range Z (µm) for Z (default 20), Number of pixels per scan (default 50), and Time (s) for the whole scan (default 1).

Typical use. After finding a spot in an image scan, move to it (right-click > Go to position), then press Optimize X, Optimize Y and Optimize Z. Repeat until the peaks stop moving.

Reading the plots.

  • The X, Y and Z plots sit side by side, and each Optimize click adds its scan to its own axis's plot.
  • Successive scans cycle through colors. The newest scan has the heavy line, with a dashed vertical line where the piezo moved to; older scans are thinner and paler.
  • All three plots share one intensity scale, so you can read across them to compare peak heights.
  • The position axis widens to fit every scan so far.
  • Each plot's title gives the other two piezo positions for its newest scan. Hover over a line to see that scan's number, time, the other two positions and where it moved the piezo.
  • Right-click in a plot and choose Go to position to move that axis there.

Reset plots clears all three plots. Save scan saves the scan picked in the Scan list, as PNG plus HDF5 or HDF5 only.

Log and saved window state

Log. The Log section under the scope shows everything that used to go to the terminal: messages, warnings and full error tracebacks. It starts folded. Its header counts errors (red) and warnings (orange), so a problem shows even while folded. Clear empties it, Copy all copies it for pasting into a message, Open log file opens the saved copy, and Follow newest keeps the newest line in view.

What is remembered between sessions.

After 2 hours the defaults apply: Laser, Flip mirrors and Power open, Stage folded, Scope open, Log folded. The state is saved when you quit and once a minute, so a crash loses at most a minute. Scans themselves are not kept between sessions; SAVE THE ONES YOU NEED.

Preferences and dark mode

File > Preferences… has four settings. Appearance picks Light or Dark colors. Flip mirrors turns automatic mirror switching on or off (below). Log > Verbose logging (off by default) writes every detail to the Log, including each instrument command and how long it took; turn it on to diagnose a problem, then send the Log. Setup profile picks which profile loads: From the desktop shortcut (the default), VQLM, TQLM, or Another profile file (type a path or use Browse…). The dialog shows the profile running now.

Appearance and profile apply when the program starts again. Save and restart saves and restarts at once (a running scan or measurement stops, and the window state is kept); Save keeps them for the next start. File > Restart restarts without changing anything.

Saved PNG images stay black on white in both themes. If the profile file chosen here can't be read, the program starts with the shortcut's profile and says so in the Log.

Automatic flip mirrors. In Preferences, tick Switch the mirrors automatically. It takes effect as soon as you press Save. Opening the Camera tab then moves the mirrors to the camera. Opening Image scan or XYZ Optimization, or starting any scan or the scope, moves them to the photon counter, and a scan waits for the mirrors to settle before it starts. Only the detection mirrors move (listed under flippers: auto: in the profile), so the 532 nm / SuperK or Santec / white light choice stays as it is. The mirrors don't move at launch, and they stay on the counter if you open the Camera tab while a scan is running.

Troubleshooting

ProblemWhat to do
The shortcut opens nothingA message box should say why. If not, open qt3microscope_console.log (below) and send it along.
Taskbar shows Python or Tk instead of QT3 MicroscopeRun the shortcut script again, unpin any old Python/Tk button, then start from the new shortcut.
Status line says "Busy: …"Another job is using the DAQ, usually a scan. Wait for it, or pause or cancel the scan.
Stage keys do nothingTick Arrow-key stepping, open the Stage section, and click outside any text box. Moves are refused during a scan.
Laser shows "unknown"Press Reconnect. If it stays unknown, check the QICK-DAWG board's USB connection. The stripes show the last known state, which may no longer be true.
Power shows "DAQ error"Press Start again; the Log has the details.
Optimize says "fit failed"The peak was not inside the range. Widen Range XY or Range Z, or increase Time.
Log header shows errorsOpen the Log, press Copy all and send it along with what you were doing.
"Is the SPCM on?" windowThe first reading was 0 counts. Switch on the SPCM and check its cable; the window closes when counts arrive.
Camera shows nothingPress Play. If ThorCam has the camera, close ThorCam first. Check the mirrors are on the camera preset.

Files and settings

If something goes wrong, the most useful file is C:\Users\QT3 User Facility\.qt3utils\qt3microscope_console.log, which holds everything shown in the Log (the run before is qt3microscope_console.prev.log). The full list of files the program keeps, and the setup profile, are in the developer guide.
